# Working names

- **Company:** Bare Signal
- **Product:** Unspool
- **Tagline:** See what you send.

Bare Signal expresses the intended philosophy: essential information, plainly visible. It can accommodate a small family of tools without restricting the company name to chat or a particular model.

Unspool names an action: reveal the thread that makes up the request. It connects conversation history, source text, and the assembled model input without requiring a new technical term. It also reads naturally as a prospective terminal command: `unspool`.

The tagline describes a verifiable product behavior. Use it alongside an explicit simulation label in the web demonstrator; the demo assembles requests locally and does not send them to a model.

## Light collision scan

An initial web search on September 30, 2026 found existing uses of both working names:

- [Bare Signal](https://www.baresignal.studio/) is a branding studio.
- [Unspool](https://www.unspool.app/) is a Mac application for adding metadata to scanned film photographs.

These are different markets, but the names are already in use. Treat this pair as a design direction, not a cleared commercial identity. The scan did not establish trademark rights, company-name availability, domain availability, or package/command ownership.

Other candidates had closer overlap with this product category:

- **Pith:** an existing [CLI for structured LLM codebase context](https://github.com/moradology/pith) and an [AI agent memory product](https://getpith.dev/).
- **Pane:** an existing [AI agent product](https://www.withpane.com/).
- **Plainwork:** existing [AI workflow software](https://www.plainwork.com/).

Fresh compounds such as Baretrace / Sendpane are more literal, but less memorable. Bare Signal / Unspool is the preferred working direction because the company philosophy and product action complement each other.
